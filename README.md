# VPNi — Android

Official off-store releases of the **VPNi** Android app (`com.vpni.android`).

Fast, private VPN with per-app split tunnelling, a real kill switch, and smart
server selection.

## Download

Grab the latest signed APK from the **[Releases](https://github.com/DigitalDTech/vpni_app/releases/latest)** page.

1. Download `vpni-vX.Y.Z.apk` from the latest release.
2. Open it on your Android device.
3. If prompted, allow installs from your browser / file manager ("unknown sources").

Existing users are updated in-app automatically.

## Stay updated automatically (recommended)

Use **[Obtainium](https://github.com/ImranR98/Obtainium)** to get update
notifications the moment a new version ships:

1. Install Obtainium.
2. Add app → paste: `https://github.com/DigitalDTech/vpni_app`
3. Obtainium tracks every release and prompts you to update.

## Verify your download

Each release lists the APK's SHA-256. To check it:

```bash
sha256sum vpni-vX.Y.Z.apk
```

Compare the output to the checksum in the release notes.
